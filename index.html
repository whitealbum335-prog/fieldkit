    Compromised password check

    Check whether a password appears in HIBP’s public Pwned Passwords dataset. The password stays in this browser.

    Fieldkit hashes the password locally and sends only the first 5 characters of its SHA-1 hash to Have I Been Pwned over HTTPS. The service returns a range of hash suffixes; Fieldkit matches locally and discards the rest. The password field is cleared after each check. This check is not an email-breach search.
